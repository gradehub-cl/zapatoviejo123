# Código editable

Edita el archivo del tema. `orden.json` ensambla los siete scripts de raíz sin
transformarlos; no edites ni commitees esos generados.

- Localizar: `npm run buscar -- nombreOTexto`.
- Leer una función: `npm run buscar -- --ver nombreFuncion`.
- Actualizar al guardar: `npm run js:watch`.
- Compilar y probar: `npm run build` y `npm test`.
